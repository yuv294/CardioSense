# CardioSense v1 (archived)

The original pipeline: four models trained on the Kaggle `framingham.csv` (one visit,
4,240 people), compared with the Framingham office score. Result: no model beat the
score (AUROC about 0.70 for all). Kept for reference and for the v1 → v2 comparison in
the main README. These scripts expect the old folder layout and are not maintained.
